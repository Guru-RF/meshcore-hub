      Join on RF

      Any MeshCore repeater or companion can join the network over the air. Every node uses the same radio settings:

      Frequency434.890 MHz
      Bandwidth62.5 kHz
      Spreading factor8
      Coding rate4/8
      Sync wordMeshCore default (private, 0x12)

      On a stock MeshCore repeater, enter this on its command line (serial, or remote admin in the app), then reboot it:

      set radio 434.890,62.5,8,8
reboot

      The last value is the coding rate's denominator: 8 means 4/8. The settings apply after the reboot.

      In the MeshCore app, set the same frequency, bandwidth, spreading factor and coding rate in the radio settings.

      Channels

      Scan a code with the MeshCore app to add the channel. A hashtag channel can also be joined by typing its name in the app. These channels are public: anyone with the key can read them.

      Connect a repeater or hotspot to the backbone

      The backbone joins RF islands over the internet and feeds this map. A repeater opens a UDP session to the hub, so it works behind NAT and on 4G. When the hub is unreachable the repeater carries on exactly as before.

      1. Run meshcore-repeater with the backbone support.
      2. Send the hub operator your callsign and your node's public key: the pub= line of repeater.key. Club calls (ON0…) show as repeaters, personal and vanity calls as hotspots.
