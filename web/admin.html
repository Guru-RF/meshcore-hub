Create your passkey

A passkey replaces a password: it lives on this device (or your phone or password manager) and is unlocked with your fingerprint, face or PIN. You can add more devices later with a new invite.

Sign in

Room admins sign in with the passkey they created from their invite.

No account? Admins are invite only: ask an existing admin.

Rooms

A room is a hashtag channel plus the transport region with the same key. Every backbone node serves the rooms here on top of its own, and the portal shows their messages.

    Messages

    Every decoded channel. The public map shows only the default Public channel.

      Blocked users

      Blocks apply at the hub and on every node on the backbone; repeaters that are only on RF still relay a blocked user. A group message carries only the name its sender chose, so a name block is easy to dodge; a key block stops one identity's adverts.

        Senders, last 7 days

          Nodes

          Each node reports which set of rooms and blocks it applied. Older firmware, or a node with backbone_policy = false, doesn't take them.
